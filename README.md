# Project Management Platform

A full-stack project management platform designed for managing workspaces, projects, tasks, issues, and team collaboration.

## Features

- Workspace and project management
- Task and issue management
- Team collaboration
- User authentication
- Responsive web interface
- State management with Redux
- PostgreSQL database
- Prisma ORM

## Tech Stack

### Frontend
- React
- Redux
- Tailwind CSS

### Backend & Database
- Node.js
- PostgreSQL
- Prisma

## Project Structure

The application follows a full-stack architecture with a React frontend, backend APIs, and a PostgreSQL database.

## Purpose

This project demonstrates full-stack web application development, database integration, state management, and collaborative project-management workflows.
